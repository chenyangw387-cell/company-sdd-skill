# Company SDD Skill

将 SDD 开发流程整理为 Codex Skill，支持新项目启动、已有项目引入、需求与计划编写、实现及独立验收。

## 文件说明

- company-sdd/SKILL.md：Skill 主入口。
- company-sdd/agents/：界面配置。
- company-sdd/references/：流程参考资料。
- company-sdd/assets/templates/：项目和功能规范模板。

请保留完整的 company-sdd 文件夹，不能只复制 SKILL.md。

## 资料来源

流程原文及模板来自 LearnLLM.AI 的 SDD 课程配套项目：
https://github.com/learnllm-ai/SDD_Starter

本项目为个人整理的 Skill，并非 LearnLLM.AI 官方发布。
